# ADR-0001: Server-generated UUIDv7 identifiers

**Status:** accepted
**Date:** 2026-09-26

## Context

The spec requires UUIDv7 on Python 3.12+, which lacks a standard-library UUIDv7
generator. IDs should not require a PostgreSQL extension.

## Decision

Generate RFC 9562 UUIDv7 from Unix milliseconds and 74 cryptographically random
bits, with explicit version and variant bits. Store PostgreSQL UUIDs. Separate
client capture keys accept any UUID version.

## Consequences

IDs sort by timestamp but are not monotonic within a millisecond or across clock
adjustments. Use `created_at` for authoritative time. Tests cover bit layout,
version, variant and uniqueness without an additional dependency.
